# راه‌اندازی اولیه API وام کمالی

این پوشه شروع بک‌اند PHP/MySQL است؛ تا زمانی که روی هاست آپلود و تنظیمات انجام نشده، اپ‌ها به آن وصل نیستند.

## فایل‌ها
- `api/index.php`: بررسی سلامت سرویس و خواندن آگهی‌های فعال
- `api/config.example.php`: نمونه تنظیمات اتصال
- `database/schema.sql`: ساخت جدول آگهی‌ها

## نصب در cPanel
1. در File Manager یک پوشه مانند `public_html/api` بسازید.
2. محتوای `backend/api` را در آن قرار دهید تا مسیر `/api/index.php` ایجاد شود.
3. فایل `config.example.php` را در همان پوشه کپی و نام آن را `config.php` کنید.
4. در `config.php` نام دقیق دیتابیس، کاربر و رمز را وارد کنید. مقدار `db_host` را از پشتیبانی هاست بگیرید؛ `localhost` فقط یک مقدار نمونه است.
5. از بخش phpMyAdmin فایل `database/schema.sql` را در دیتابیس درست Import کنید.
6. بعد از فعال شدن دامنه و HTTPS، آدرس `https://YOUR-DOMAIN/api/index.php?action=health` را باز کنید. مقدار `configured` فقط وجود فایل تنظیمات را نشان می‌دهد و به معنی اتصال موفق دیتابیس نیست.
7. سپس `https://YOUR-DOMAIN/api/index.php?action=ads` را آزمایش کنید؛ تا وقتی تنظیمات و جدول آماده نباشد، خطای تنظیم‌نشدن یا دیتابیس می‌دهد.

## امنیت و وضعیت فعلی
- رمز دیتابیس را در GitHub قرار ندهید؛ فایل واقعی `config.php` نباید وارد مخزن شود.
- این نسخه فقط نقطه شروع است: احراز هویت مدیر، ثبت درخواست عضو، اعتبارسنجی، محدودسازی درخواست‌ها و اتصال رابط‌های دو اپلیکیشن هنوز پیاده‌سازی نشده‌اند.
- برای استفاده واقعی، ابتدا HTTPS، احراز هویت امن مدیر و محافظت از داده‌های کاربران باید تکمیل و آزمایش شود.


## تغییر ورود به شماره موبایل و مشخصات اعضا

برای دیتابیسی که قبلاً جدول `members` دارد، پیش از انتشار نسخه جدید اپلیکیشن، فایل `database/migration_member_phone.sql` را یک‌بار در phpMyAdmin اجرا کنید. این مهاجرت ستون‌های نام، نام خانوادگی و شماره موبایل را اضافه می‌کند و شماره موبایل را یکتا می‌سازد؛ حساب‌های قبلی حذف نمی‌شوند.

**مهم برای مدیر فعلی:** چون شماره موبایل مدیر از نام کاربری قبلی قابل حدس‌زدن نیست، پس از اجرای مهاجرت باید شماره موبایل واقعی مدیر را در phpMyAdmin برای رکورد مدیر ثبت کنید. نمونه دستور در فایل مهاجرت آمده است. پس از آن ورود پنل مدیریت نیز با شماره موبایل و رمز عبور انجام می‌شود.

ثبت‌نام عضو جدید فقط با نام، نام خانوادگی، شماره موبایل و رمز عبور انجام می‌شود. نام و نام خانوادگی در فرم اجباری‌اند؛ فیلدهای اختیاری دیگری به این فرم اضافه نشده‌اند.

وام کمالی — پروژه آزمایشی GitHub Actions برای ساخت دو APK

این پروژه دو اپلیکیشن اندرویدی آزمایشی می‌سازد:
- members-app: اپ اعضا (دارای فرم آزمایشی درخواست دسته‌چک)
- manager-app: اپ مدیر

نکته مهم:
- این‌ها فعلاً پوسته WebView روی HTML هستند و به هم یا به سرور وصل نیستند.
- سفارش‌های اعضا در پنل مدیر ظاهر نمی‌شوند تا زمانی که بک‌اند امن ساخته و متصل شود.
- این نسخه برای آزمایش رابط کاربری است؛ اطلاعات واقعی بانکی، رمزها یا مدارک هویتی وارد نکنید.
- APKهای تولیدشده در GitHub Actions بخش Artifacts هستند، نه Release.

روش راه‌اندازی:
1. فایل ZIP را استخراج کنید.
2. تمام محتویات داخل پوشه vam_kamali_github_build را به ریشه یک مخزن GitHub جدید آپلود کنید؛ فایل .github/workflows/build-apks.yml باید در همین مسیر باشد.
3. نام شاخه اصلی را main بگذارید (یا تنظیم workflow را با شاخه مخزن هماهنگ کنید).
4. در مخزن، تب Actions را باز کنید و workflow با نام Build Android APKs را اجرا کنید.
5. پس از پایان موفق، اجرای workflow را باز کنید و هر دو Artifact را دانلود کنید.
6. هر Artifact یک ZIP است که داخلش app-debug.apk قرار دارد.

محدودیت:
این بسته، سورس و تنظیمات ساخت ابری را آماده می‌کند. ساخت موفق باید در حساب GitHub شما اجرا و تأیید شود.
